# Inside the Game — 90–120 second demo

**0:00–0:15 · Establish trust**  
Show the tied score and the “Synthetic Data / Hackathon Prototype” label. Say: “This match and every person in it are fictional. We’ll show how the application separates events, calculations, and interpretation.”

**0:15–0:35 · Personalize**  
Select Harbor City and a favourite player. Switch from Analyst View to Fan View and back to show the same match can speak to two audiences.

**0:35–0:55 · Generate the signal**  
Press **Start**. Point to Harbor City’s high pressure, interception, and forward pass in the live timeline. The scenario is seeded, so the same demo can be replayed.

**0:55–1:15 · Explain the insight**  
Read the priority insight, confidence, and linked event IDs. Briefly show the event map and the clearly labelled calculated proxies. Open a supporting event from its evidence link.

**1:15–1:35 · Prove the workflow**  
Show the trace steps: Event Intelligence → Tactical Analysis → Narrative & Personalization. Call out the supporting IDs and alternative explanation. The trace shows concise rationale, not hidden chain-of-thought.

**1:35–1:50 · Tell the story**  
Switch to Fan View. Read the short commentary and favourite-player highlight in plain English.

**1:50–2:00 · Close**  
Let the scripted synthetic goal arrive, then reset. End with: “Every insight is traceable to generated evidence, and the demo works locally without cloud credentials.”
